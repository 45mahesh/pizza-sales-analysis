\# Dataset Description



This project uses a pizza sales dataset consisting of 4 CSV files:



\## Files



\- orders.csv: Contains order date and time

\- order\_details.csv: Contains order line items and quantities

\- pizzas.csv: Contains pizza size and pricing information

\- pizza\_types.csv: Contains pizza categories and ingredients



\## Notes



\- Data represents one year of sales

\- Used for analyzing revenue, demand patterns, and product performance
